# LJY2231 个人主页

二次元卡片风格个人网站主页。

## ✨ 功能

- 🎨 **随机二次元背景**：每次刷新换图，右上角设置里可一键更换背景（桌面/手机端分别用横版/竖版图源，渐变过渡）
- 🎵 **音乐播放器**（左下角）：本地 mp3 播放，不依赖任何音乐接口；上一曲/下一曲/随机播放、进度条点击跳转、旋转封面
- 📝 **歌词面板**（左上角）：按"歌名+歌手"从 LRCLIB 搜索歌词（支持指定歌词 URL），5 行居中滚动、切行上滑动画、双语歌词拆行
- 🐋 **小鲸鱼挂件**（右下角）：点击随机台词、可拖拽、按压 Q 弹、四种音效（小黄鸭/音效1/钢管落地）、可隐藏
- ⚙️ **右上角设置**：更换背景图、重新载入歌曲、重新加载小鲸鱼
- 📊 不蒜子访客统计（数字滚动动画）、本站运行时长计时（滚数动画）
- ✨ 文字逐行浮现动画、响应式适配（手机端卡片居中、音乐/歌词不自动展开）

## 🚀 部署

任意静态服务器即可，推荐使用仓库自带的 Range 服务器（音频进度跳转必需）：

```bash
python serve.py
# 访问 http://127.0.0.1:8000
```

也可部署到 GitHub Pages / Nginx / 任意静态托管。

## ⚙️ 配置

### 添加歌曲

1. 把 mp3 放到 `static/music/`
2. 在 `static/main.js` 的 `LOCAL_SONGS` 数组加一行：

```js
{ name: "歌名", artist: "歌手", url: "./static/music/文件名.mp3" }
```

可选字段：
- `pic`：封面图路径（`static/covers/`）
- `lrcUrl`：指定歌词直链（如网易云歌词代理），优先于自动搜索
- `lrcName` / `lrcArtist`：指定歌词搜索用歌名/歌手（DJ/翻唱版按原曲搜索）

### 更换背景图源

编辑 `static/main.js` 的 `BG_LIST`（桌面）和 `BG_LIST_MOBILE`（手机）数组，填入你的随机图床 URL。

### 运行时长起始日期

编辑 `static/main.js` 中 `var start = new Date("2026/08/29")` 为你的实际上线日期。

### 其他

- 一言 API、不蒜子统计、导航按钮链接都在 `index.html` 中修改。

## 📁 目录结构

```
├── index.html          页面主体
├── serve.py            本地静态服务器（支持 Range）
├── static/
│   ├── main.js         逻辑（播放器/歌词/设置/动画）
│   ├── whale.js        小鲸鱼挂件
│   ├── style.css       样式
│   ├── canvas-nest.min.js   粒子背景
│   ├── layer-v3.5.1/   layer 弹窗库
│   ├── music/          本地 mp3
│   ├── lyrics/         本地歌词文件
│   ├── covers/         歌曲封面
│   └── sounds/         小鲸鱼音效
```
